Nivel 4 — Diagrama de Código

Clases del componente Order Service (HU-04: Proceso de Compra).

classDiagram
    class OrderController { +createOrder(req, res) }
    class OrderService {
        -orderRepo
        -productRepo
        -paymentService
        +placeOrder(buyerId, productId, paymentData) Order
        -validateNotSameSeller(buyerId, sellerId) boolean
        -validateAvailability(product) boolean
    }
    class PaymentService { +charge(amount, paymentData) PaymentResult }
    class OrderRepository { +create(order) Order  +findById(id) Order }
    class ProductRepository { +findById(id) Product  +updateStatus(id, status) Product }
    class Order { +id +buyerId +productId +status +amount +createdAt }
    class Product { +id +sellerId +title +price +status }
    class PaymentResult { +success +transactionId }
    OrderController --> OrderService : usa
    OrderService --> OrderRepository : usa
    OrderService --> ProductRepository : usa
    OrderService --> PaymentService : usa
    OrderService ..> Order : crea
    OrderRepository --> Order : persiste
    ProductRepository --> Product : persiste
    PaymentService --> PaymentResult : retorna
